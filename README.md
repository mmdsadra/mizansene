# Mizansene

A local-first food shopping assistant for Okala.

Mizansene helps you find the ingredients you need for a meal and locate
matching products available on Okala.

## Features

- Search Okala products
- Search ingredients by food or recipe
- Match recipe ingredients to available products
- Show product images
- Open products directly on Okala
- Keep a local product/history cache
- Desktop GUI
